# 🏢 LeadSense-AI — Real Estate Lead Intelligence Platform

> **AI-Powered Real Estate Lead Scoring & Buyer Dossier System**  
> Custom-Branded & Integrated for **SLV Builders & Developers**  
> 🔗 Official Partner Site: [SLV Builders & Developers](https://sites.google.com/view/slvbuildersanddevelopers/home?pli=1)

---

## 🌟 Key Features

- **4-Dimensional AI Lead Scoring Engine (0–100)**:
  - **Intent**: Page views, visit requests, saved listings, inquiry frequency.
  - **Affordability**: Annual income, max budget, loan pre-approval status.
  - **Location Fit**: Micro-market matching across Hyderabad real estate hubs.
  - **Transaction Readiness**: Document completion, move-in timeline, decision stage.

- **SLV Builders Real-World Integration**:
  - Integrated projects: **SLV Lorven**, **SLV Paradise**, **SLV Residency**, **SLV Green Meadows**, **SLV Prime Heights**, and **SLV Signature Villas**.

- **Dual-Portal Architecture**:
  - **Director / Agent Intelligence Console**: High/Medium/Low priority splits, 4D Radar Charts, location analytics, interactive "What-If" AI simulator, phone number editor, CSV report exporter, and client account deletion.
  - **VIP Client Portal**: Personalized buyer dossier, property match index, site visit scheduler, profile photo manager, and direct contact with SLV Relationship Manager.

- **Account & Session Security**:
  - Real-time client registration with customizable profile photos & phone numbers.
  - Local session persistence across page refreshes (`localStorage`).
  - Option to delete client accounts permanently.

---

## 🛠️ Technology Stack

- **Frontend Framework**: React 18 + Vite
- **Icons**: Lucide React
- **Analytics & Data Vis**: Recharts
- **Styling**: Modern Vanilla CSS with dark/light mode toggle & glassmorphism tokens
- **Dataset**: 200 real estate buyer/tenant records enriched with INR currency metrics

## 🚀 How to Run Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/LeadSenseAI.git
   cd LeadSenseAI
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```

## 📦 How to Push to GitHub

1. **Install Git** (if not installed on your system): Download from [git-scm.com](https://git-scm.com/downloads).
2. **Create a new repository** on [GitHub](https://github.com/new) (e.g. `LeadSenseAI`).
3. **Run the following commands** in your terminal inside the project directory:

```bash
git init
git add .
git commit -m "Initial commit: LeadSense-AI platform for SLV Builders"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/LeadSenseAI.git
git push -u origin main
```
